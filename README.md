## 🚀 Overview

This project is a **Command-Line Contact Book** that helps users manage their contacts efficiently using Python.
It supports full **CRUD operations (Create, Read, Update, Delete)** with a clean and interactive interface.

---

## ✨ Features

* ➕ Add Contact<br>
* 📋 View All Contacts<br>
* 🔍 Search Contact<br>
* ✏️ Update Contact<br>
* 🗑️ Delete Contact<br>
* ⚠️ Input Validation<br>

---

* Python 🐍<br>
